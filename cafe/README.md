# Typing Cafe

Elementary English typing practice game.

## Run

Open `index.html` directly in a browser, or run a small static server from this folder:

```bash
python3 -m http.server 5174
```

Then visit:

```text
http://127.0.0.1:5174/
```

## Game

- Type the English word shown on an order ticket.
- Correct words serve the order and add food to the served tray.
- Serve enough orders to move to the next level.
- Orders arrive faster and patience gets shorter as levels increase.
- The game tracks score, combo, accuracy, level, and served order count.
