# Typing Fishing

Elementary English typing practice game.

## Run

Open `index.html` directly in a browser, or run a small static server:

```bash
python3 -m http.server 5173
```

Then visit:

```text
http://127.0.0.1:5173/
```

## Game

- Type the English word shown on a fish.
- Correct words catch fish and add them to the aquarium.
- Start from level 1, 3, or 5.
- Catch enough fish to move to the next level.
- Fish spawn faster and swim faster as levels increase.
- The game tracks score, combo, accuracy, level, and catch count.
